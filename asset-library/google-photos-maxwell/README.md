# Maxwell Ventures Google Photos Asset Library

This folder is a repo-side working library for Maxwell Ventures visual assets found through Google Photos search and local ChatGPT image exports.

It is not the raw photo archive. Do not add Google Photos URLs, Google asset IDs, EXIF, GPS data, private albums, or unapproved personal/source files here.

## Contents

- `manifest.csv`: labeled inventory of candidate assets and vector exports.
- `previews/`: re-encoded WebP preview derivatives for review and design reference.
- `svg-source/`: large vector exports copied from the local Maxwell Ventures website asset folder.

## Privacy Boundary

Treat every item as owner-review until Max explicitly approves it for public production use.

Keep these out of this repository unless separately approved:

- raw Google Photos downloads
- unapproved portraits or personal photos
- private Google Photos links, IDs, albums, and metadata
- EXIF/GPS metadata
- customer, client, or third-party visuals
- rejected logo variants that should not become public

## Promotion Path

Website-ready assets belong in:

- `public/brand/`
- `public/images/team/`
- `public/images/backgrounds/`
- `public/images/icons/`
- `public/images/brand-world/`
- `public/social/`

The public homepage now uses selected derivatives from `public/images/brand-world/` after Max's June 4, 2026 publish approval. The remaining candidates in this library still require explicit promotion before public use.
